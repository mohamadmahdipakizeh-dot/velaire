Project Overview

Velaire is a restaurant website designed and built using WordPress and Elementor. The project focuses on presenting the restaurant, showcasing its food menu, and making contact information and reservation inquiries easily accessible.

Features

- Responsive layout for mobile and tablet devices
- Food menu and dish presentation
- Food prices and related information
- Image gallery
- Restaurant service overview
- Contact information and contact form
- Reservation inquiry section
- Visual animations and interactions
- Customized page layouts and styling

Technologies

- WordPress
- Elementor
- HTML
- CSS
- JavaScript
- GitHub Pages for static deployment

My Contributions

- Designed and implemented nearly all website sections
- Prepared the main website content
- Selected and prepared images and visual assets
- Customized styling with CSS
- Debugged code and refined page presentation
- Prepared and deployed the static website version
